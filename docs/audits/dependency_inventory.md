# Dependency Inventory Report

## Runtime Dependencies (`requirements.txt`)
- `fastapi`: Async ASGI web framework.
- `uvicorn`: High-performance ASGI server.
- `httpx`: Modern HTTP client with HTTP/2 and async connection pooling.
- `pydantic`: Type safety and payload schema validation.
- `beautifulsoup4`: HTML parsing and DOM scraping for security crawlers.
- `cryptography`: Cryptographic primitives and certificate inspection.
- `sqlite3`: Native C-driver included with Python standard library.

## Zero Vulnerability Policy
All pinned and installed dependencies have been audited against CVE databases; no unpatched known high/critical CVEs exist in the direct dependency tree.
