## 2. Quickstart Execution Commands

### Windows:
```cmd
cd SWA
run.bat
```
Or with PowerShell:
```powershell
Set-Location C:\Users\krish\SWA
.\run.ps1
```

### Linux & macOS:
```bash
cd SWA
chmod +x run.sh
./run.sh
```

### Direct Python Execution:
```bash
python run.py
```

The application will start on **`http://127.0.0.1:8000`** and automatically launch your default browser.
